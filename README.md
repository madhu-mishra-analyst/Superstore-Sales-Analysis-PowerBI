# Executive Sales & Profitability Overview Dashboard

An interactive Power BI dashboard designed to analyze retail sales performance, profitability margins, customer segments, and regional distributions.

## 📊 Key Metrics Summary

* **Total Sales:** $88.37K
* **Total Profit:** $15.44K
* **Overall Profit Margin:** 17.47%

## 🔍 Key Dashboard Insights

* **Sales by Segment:**
  * **Consumer:** Generates the largest share of sales at **49.9%** ($44.09K).
  * **Corporate:** Accounts for **34.97%** ($30.9K).
  * **Home Office:** Accounts for **15.14%** ($13.38K).

* **Sales by Category:**
  * **Office Supplies:** $35,870.98
  * **Furniture:** $26,378.34
  * **Technology:** $26,117.19

* **Product Performance (Sub-Category Profit Margins):**
  * **Highest Margin:** **Copiers** yield the highest profit margin percentage.
  * **Lowest/Negative Margin:** **Tables** operate at a negative profit margin.

* **Geographic & Filtering Features:**
  * Interactive map visual tracking sales locations across regions (Central, East, South, West).
  * Dynamic filters for **Ship Mode** (*First Class, Same Day, Second Class, Standard Class*) and **Order Date range**.

## 🛠️ Tools & Technologies Used
* **Power BI Desktop**
* **DAX** (Calculated Measures for Profit Margin %)
* **Data Visualization & Modeling**
